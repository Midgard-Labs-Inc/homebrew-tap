# Midgard Labs Homebrew tap

This repository contains formulas for installing aiken's projects using [Homebrew](https://brew.sh) on Mac.

## Installing

To fetch the tap, just run `brew tap Midgard-Labs-Inc/homebrew-tap`. You can also just install any Aiken project by name:

### Aiken

```sh
brew install Midgard-Labs-Inc/homebrew-tap/aiken
```
